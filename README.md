## 📌 Project Overview

The **Swiggy Sales & Business Performance Dashboard** is an interactive Power BI project developed to analyse business performance across sales, orders, customer demographics, and restaurant operations.

The dashboard provides meaningful insights through interactive visualisations, KPI cards, charts, and filters. It helps users understand business trends, customer behaviour, and restaurant performance.

## 📊 Dashboard Pages

### 🏠 1. Home

The Home page serves as the landing page of the dashboard.

**Features:**
- Introduction to the Swiggy platform.
- Navigation to all dashboard sections.
- Swiggy-inspired orange theme.
- User-friendly dashboard layout.

### 📈 2. Overview

The Overview page provides a summary of overall business performance through important KPIs and visualisations.

**Key Performance Indicators (KPIs):**
- Total Amount
- Total Orders
- Total Customers
- Total Restaurants
- Average Order Value
- Total Quantity Sold

**Business Analysis:**
- Top 3 Customers by Sales Amount.
- Top 5 Restaurants by Sales Amount.
- Quarterly Sales Trends.
- Quarterly Quantity Trends.

### 💰 3. Sales & Order Performance

This page focuses on analysing sales and order trends across different time periods.

**Key Analysis:**
- Monthly Order Count.
- Sales Performance Trends.
- Quantity Sold Trends.
- Month-wise Sales Comparison.
- Year-wise Sales Comparison.
- Sales by Gender.
- Interactive Year and Month Filters.

### 👥 4. Customer Demographics & Behaviour

This page provides insights into customer demographics and behaviour patterns.

**Key Analysis:**
- Customer Distribution by Marital Status.
- Customer Distribution by Occupation.
- Customer Distribution by Gender.
- Customer Distribution by Age Group.
- Interactive Year and Month Filters.

### 🍽️ 5. Restaurant Performance Analysis

This page evaluates restaurant performance based on ratings, pricing, sales, and geographical distribution.

**Key Performance Metrics:**
- Total Restaurants.
- Average Restaurant Rating.
- Average Restaurant Price.

**Restaurant Analysis:**
- Restaurant Rating Distribution.
- Restaurant-wise Rating Count.
- Restaurant-wise Average Rating.
- Top 7 Restaurants by Sales.
- Restaurant Distribution by City.

## 🚀 How to Use

1. Open the Google Drive link provided in the Project Files section.
2. Download the Power BI (`.pbix`) file and required dataset.
3. Open the `.pbix` file using Microsoft Power BI Desktop.
4. Connect the dataset if prompted.
5. Update the data source path if necessary.
6. Refresh the data.
7. Explore all five dashboard pages using interactive filters and navigation.
